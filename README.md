# AI Travel Planner using CrewAI

An AI-powered travel planning application built using **CrewAI**, **OpenRouter**, **Serper Web Search**, and **Streamlit**.

The application uses multiple AI agents to research a destination, estimate the travel budget, and generate a personalized day-by-day itinerary.

---

## Project Overview

The AI Travel Planner is a multi-agent AI application that automates travel planning.

Instead of using a single AI agent, the project uses three specialized CrewAI agents:

1. **Research Agent** – Searches the web for current travel information.
2. **Budget Agent** – Creates a realistic budget based on the destination and user's budget.
3. **Travel Planner Agent** – Combines the research and budget information to create a complete itinerary.

# AI Agents

## 1. Research Agent

The Research Agent is responsible for collecting current travel information.

### Responsibilities

* Search tourist attractions
* Find popular activities
* Find local food
* Search accommodation areas
* Find transportation options
* Find approximate prices
* Find opening hours
* Collect travel tips

The agent uses:

```text
CrewAI
   |
   +--- OpenRouter → LLM
   |
   +--- Serper → Web Search
```

---

## 2. Budget Agent

The Budget Agent uses the research generated by the Research Agent.

It creates an estimated budget for:

```text
Accommodation
Food
Transportation
Attractions
Activities
Miscellaneous
```

The agent attempts to keep the total cost within the user's maximum budget.

---

## 3. Travel Planner Agent

The Travel Planner Agent combines:

```text
Research Report
       +
Budget Report
       |
       v
Final Itinerary
```

It generates a day-by-day travel plan containing:

* Morning activities
* Afternoon activities
* Evening activities
* Places to visit
* Food recommendations
* Estimated daily cost
* Travel tips
* Budget summary

# CrewAI Workflow

The project uses a sequential CrewAI process.

```text
Task 1
Research Destination
       |
       v
Task 2
Calculate Budget
       |
       v
Task 3
Create Itinerary
```

In `crew.py`:

```python
travel_crew = Crew(
    agents=[
        research_agent,
        budget_agent,
        planner_agent
    ],

    tasks=[
        research_task,
        budget_task,
        planning_task
    ],

    process=Process.sequential,

    verbose=True
)
```

---

# Agent Communication

The agents work together rather than independently.

```text
Research Agent
      |
      | Research Report
      v
Budget Agent
      |
      | Budget Report
      v
Travel Planner Agent
      |
      v
Final Travel Plan
```

The Budget Agent receives the Research Agent's output.

The Travel Planner Agent receives both:

```text
Research Report
       +
Budget Report
```

# Web Search Integration

The Research Agent uses:

```python
from crewai_tools import SerperDevTool

search_tool = SerperDevTool()
```

The tool is assigned to the Research Agent:

```python
research_agent = Agent(
    ...
    tools=[search_tool],
    ...
)
```

This allows the Research Agent to perform web searches instead of relying only on the LLM's existing knowledge.

---

# OpenRouter Integration

The project uses OpenRouter as the LLM gateway.

Example:

```python
from crewai import LLM

llm = LLM(
    model="openrouter/openai/gpt-4o-mini",
    temperature=0.3
)
```

OpenRouter allows the application to access different supported LLMs through a common API.

The model can be changed in `agents.py` without changing the overall CrewAI architecture.

# Security

Never commit API keys.

Do not put this directly into your Python code:

```python
OPENROUTER_API_KEY = "your-secret-key"
```

Instead use:

```env
OPENROUTER_API_KEY=your-secret-key
```

and load it through environment variables.

Make sure `.env` is included in `.gitignore`.
